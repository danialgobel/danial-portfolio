# Danial Habib Abdillah — Portfolio

Personal portfolio website of **Danial Habib Abdillah**, Informatics Engineering student at **Universitas Ahmad Dahlan (UAD)**, Yogyakarta. Showcasing work across Web Development, Mobile Applications, Automation Systems, and Creative Video Production.

![Portfolio Preview](/public/images/profile.jpg)

## ⚡ Tech Stack

- **Framework**: [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Motion](https://motion.dev/) (Hardware-accelerated fluid cubic-bezier curves)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🛠️ Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `yarn`

### Installation

```bash
# Clone the repository
git clone https://github.com/danialgobel/danial-portfolio.git

# Navigate to project directory
cd danial-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
